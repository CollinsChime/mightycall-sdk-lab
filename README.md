# MightyCall SDK Lab

A development and testing project for working with browser-based Webphone SDK functionality and VoIP calling workflows.

## Overview

This project serves as a technical sandbox for exploring Webphone SDK integration and browser-based voice communication.

It provides a practical environment for experimenting with SDK initialization, call-related functionality, event handling, and front-end interaction with VoIP services.

## Project Focus

- Webphone SDK integration
- Browser-based VoIP functionality
- SDK initialization and configuration
- Call workflow testing
- JavaScript event handling
- Front-end interaction with voice services
- Technical troubleshooting and experimentation

## Technologies

- JavaScript
- HTML
- CSS
- Web APIs
- VoIP / WebRTC concepts

## Purpose

The project was created as a technical lab for developing a deeper understanding of browser-based voice applications, SDK integrations, and VoIP-related front-end development.

## Notes

This repository is intended for development, testing, and portfolio demonstration purposes.
